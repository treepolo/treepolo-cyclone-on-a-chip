# 待辦清單 / Roadmap

使用者確認的順序：**先單獨處理效能**，其餘之後依序進行。
User-agreed order: performance first, then the rest.

## 1. 區域模式效能（進行中）/ Regional-model performance (in progress)
- 效能分析按鈕：每個 GPU kernel 耗時（timestamp query），在使用者的 GTX 1650 上量測
- kernel 合併、記憶體存取優化
- 數值設定：聲波子步 6 → 4、垂直網格下密上疏（需穩定性測試）
- 評估移動巢狀（外圍粗、核心細、跟著風暴）
- 目標：5 km 颱風（目前 6.5 步/s）與 250 m 龍捲快 3–5 倍

## 2. 模擬速度控制 / Simulation speed control
- 目標倍速（真實時間 ×1、×10、×60、×600、全速）、單步、跑到 +N 小時自動暫停
- 畫面更新間隔、快轉時不更新畫面；區域與全球模式都要

## 3. 區域模式圖表 / Regional-model charts
- 高度滑桿＋水平切面：模擬雷達回波 dBZ、w、風速／箭頭／流線、θ′／θe、RH、渦度、p′
- 合成圖：最大回波、紅外雲頂、海平面氣壓等壓線、即時降雨率、上升氣流螺旋度 UH、CAPE／CIN
- 垂直剖面：自己畫線的剖面、颱風半徑–高度軸對稱圖
- 點探空（斜溫圖＋風徑圖）、單點時間序列
- 颱風時間序列（最低氣壓、最大風速、最大風速半徑）與半徑–時間圖（Hovmöller）
- 超大胞指標（最大上升速度、地面渦度、UH、路徑）；3D 可切換變數、軌跡粒子
- GPU 上先算好診斷量，只讀回切面；全球模式圖表之後再加

## 4. 颱風雨帶診斷與修正 / Tropical-cyclone rainbands
- 現況：只有眼牆有雲
- 檢查弱風區地面通量（最小陣風 3–5 m/s）、中層濕度、輻射冷卻、水平混合、邊界與範圍
- 雨帶是多重眼牆的前提

## 5. 多重眼牆與眼牆置換 / Multiple eyewalls and eyewall replacement
- 雙眼牆、可能三重以上，以及置換循環；約 2–3 km，建議移動巢狀；用 Hovmöller 圖驗證

## 6. 龍捲 / Tornadoes
- 目前 250 m 從未產生龍捲
- 地面垂直加密（約 50 m）、先 1 km 養成熟超大胞再切 250 m 跟隨、強低層風切探空、龍捲偵測器

## 7. 互動機制 / Interaction
- 點擊放暖泡／冷池、筆刷塗海溫、放山／陸地、跑到一半改環境風切與濕度
- 自由飛行相機、挑戰任務；只改條件，不改結果

## 8. 模擬存檔與讀檔 / Save and resume simulations
- 下次直接開啟之前的模擬繼續跑；全球與區域模式、嵌入巢狀
- 瀏覽器端自動存檔清單（IndexedDB）＋匯出／匯入檔案；可倒回某個時間點

## 延後 / Deferred
- R7 雲輻射（背景氣候模擬測試，改善澳洲季風）
- 颱風追蹤（全球模式自動找熱帶擾動、巢狀跟隨）
- 第三層 250–500 m 小盒子
- 發布 7 月起轉狀態檔；T170 穩定性結果
